# URBAN PULSE\nCitizen Complaint Intelligence & Resolution Analytics.\n\n## Run locally\n1. Install requirements: `pip install -r requirements.txt`\n2. Set `DB_PASSWORD` as an environment variable or create `.streamlit/secrets.toml` using the example.\n3. Run: `python -m streamlit run app.py`\n\nThis application connects to PostgreSQL database `urban_pulse_db`, table `service_requests`. Do not upload database passwords or private credentials to GitHub.\n
